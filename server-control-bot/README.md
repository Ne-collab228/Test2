# Telegram-бот «пульт» для сервера

Телеграм-бот для мониторинга и управления сервером (headless Linux) прямо с телефона,
плюс **мини-браузер с тыком по сетке**. Long-polling — **входящие порты не нужны**.
Доступ только у авторизованного владельца.

Есть кнопки снизу (reply-клавиатура) и автоподсказки команд при вводе «/».

## Мониторинг и управление

| Команда | Что делает |
|---|---|
| `/stats` | загрузка: CPU, память, диск, нагрузка (со шкалами-полосками) |
| `/info` | железо и ОС: модель CPU, ядра, RAM, ядро Linux |
| `/ps` | топ процессов по нагрузке |
| `/bots` | что запущено: чат-бот (и загружена ли в нём модель), пульт, обучение |
| `/free`, `/df` | память / диск: занято, свободно, всего |
| `/net` | проверка интернета и задержек |
| `/speed` | тест скорости диска (запись/чтение) |
| `/uptime` | аптайм и нагрузка |
| `/temp` | температура CPU (в ВМ обычно недоступна — бот так и скажет) |
| `/sh <cmd>` | выполнить команду в терминале |
| `/tail <файл>` | последние строки файла/лога |
| `/shot <url>` | один скриншот сайта |

## Мини-браузер: лазить по сайтам из Telegram

Один браузер (Playwright/Chromium) держится открытым между командами, а после каждого
действия обновляется **то же самое фото**.

| Команда | Что делает |
|---|---|
| `/open <url>` | открыть сайт — придёт скриншот с сеткой и кнопками |
| `/click <текст>` | кликнуть по ссылке/кнопке с таким текстом |
| `/click x y` | кликнуть по координатам |
| `/type <текст>` | ввести текст в активное поле |
| `/enter` | нажать Enter (например, запустить поиск) |
| `/close` | закрыть браузер |

**Двухуровневый прицел.** Телеграм не умеет ловить касания по картинке, поэтому
экран размечен кнопками:
1. на скриншоте сетка **8×8** (кнопки 1–64) — тыкаешь нужную зону;
2. зона **увеличивается** и разбивается на **5×5** — тыкаешь клетку, бот кликает туда;
3. «⬅️ Вся страница» выходит из увеличения; ⬆️ ⬇️ 🔄 🔙 ❌ — скролл, обновить, назад, закрыть.

Клик **«прилипает»** к ближайшей кнопке/ссылке в радиусе ~90 px, поэтому промахнуться
мимо мелкого элемента сложно; бот пишет, попал ли по элементу или рядом пусто.

**Ввод текста:** сначала кликни в поле, потом `/type ...` и `/enter`.

**Авто-обновление:** пока браузер открыт, бот раз в несколько секунд сверяет экран и,
если страница изменилась сама (подгрузился контент и т.п.), обновляет фото. В режиме
прицела (увеличение) авто-обновление не мешает.

Ограничения: сайты с защитой от ботов (Cloudflare-проверка «Verifying…») автоматический
браузер не пропустят — это нормально, обходить такие проверки бот не пытается.

## Безопасность

Команды выполняет **только авторизованный пользователь**. При первом запуске бот
генерирует секрет (`control_secret.txt`) и печатает его в консоль. Владелец
авторизуется один раз: `/auth <секрет>` — его Telegram-ID сохраняется в
`control_owner.txt`, и дальше бот игнорирует всех остальных (в том числе нажатия кнопок).

> ⚠️ `/sh` выполняет реальные команды на сервере. Токен, секрет и файл владельца в
> репозиторий **не коммитятся** (см. `.gitignore`). Если токен утёк — отзови через
> @BotFather.

## Установка и запуск

```bash
python3 -m venv venv && source venv/bin/activate
pip install -r requirements.txt
playwright install chromium        # если нет готового Chromium (см. SHOT_BROWSER)

# токен бота от @BotFather:
echo "ВАШ_ТОКЕН" > control_bot_token.txt    # или переменная CTL_TOKEN

python control_bot.py
```

При старте бот напечатает секрет авторизации. Отправь боту `/auth <секрет>` — и пульт твой.

## Настройки (env)

| Переменная | Назначение |
|---|---|
| `CTL_TOKEN` | токен бота (альтернатива файлу `control_bot_token.txt`) |
| `SHOT_BROWSER` | путь к готовому Chromium; если файла нет, Playwright берёт свой браузер |
| `GEMMA_STATE_FILE` | где лежит `gemma_state.txt` чат-бота (по умолчанию ищется рядом и в `../gemma-telegram-bot/`) |

## Автоперезапуск

Сторож `../ops/watchdog.sh` поднимает упавших ботов (этого и чат-бота):

```bash
nohup bash ../ops/watchdog.sh >/dev/null 2>&1 &
```

## Зависимости

Python 3.10+; Telegram API — через стандартную библиотеку. `playwright` — для `/shot` и
браузера, `Pillow` — для сетки (шрифт берётся из matplotlib или системного DejaVu, иначе
встроенный). Для строки «Чат-бот (Gemma)» в `/bots` пульт читает `gemma_state.txt`,
который пишет соседний чат-бот (`gemma-telegram-bot`).
