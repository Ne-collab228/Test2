# Telegram-бот «пульт» для сервера

Телеграм-бот для мониторинга и управления сервером (headless Linux-контейнер)
прямо с телефона. Long-polling — **входящие порты не нужны**. Доступ только у
авторизованного владельца.

Есть **кнопки снизу** (reply-клавиатура) и **автоподсказки команд** (при вводе «/»).

## Команды

| Команда | Что делает |
|---|---|
| `/stats` | загрузка: CPU, память, диск, нагрузка (со шкалами) |
| `/info` | железо и ОС: модель CPU, ядра, RAM, ядро Linux |
| `/ps` | топ процессов по нагрузке |
| `/bots` | что запущено на сервере |
| `/free` | память: занято / свободно / всего |
| `/df` | диск: занято / свободно / всего |
| `/net` | проверка интернета и задержек до сайтов |
| `/speed` | тест скорости диска (запись/чтение) |
| `/uptime` | аптайм и нагрузка |
| `/temp` | температура CPU (в ВМ обычно недоступна) |
| `/sh <cmd>` | выполнить команду в терминале |
| `/tail <файл>` | последние строки файла/лога |
| `/shot <url>` | скриншот веб-страницы |

## Безопасность

Команды выполняет **только авторизованный пользователь**. При первом запуске
генерируется секрет (`control_secret.txt`). Владелец авторизуется один раз:
`/auth <секрет>` — его Telegram-ID сохраняется в `control_owner.txt`, и дальше
бот игнорирует всех остальных.

> ⚠️ `/sh` выполняет реальные команды на сервере. Токен, секрет и файл владельца
> в репозиторий **не коммитятся** (см. `.gitignore`). Если токен утёк — отзови
> через @BotFather.

## Установка и запуск

```bash
python3 -m venv venv && source venv/bin/activate
pip install -r requirements.txt   # playwright (для /shot)
# браузер для скриншотов: системный Chromium (путь в SHOT_BROWSER внутри скрипта)

# токен бота от @BotFather:
echo "ВАШ_ТОКЕН" > control_bot_token.txt    # или env CTL_TOKEN

python control_bot.py
```

При старте бот напечатает секрет авторизации в консоль. Отправь боту
`/auth <секрет>` — и пульт твой.

## Зависимости

- Python 3.10+, стандартная библиотека (Telegram API через `urllib`)
- `playwright` — только для команды `/shot` (скриншоты). Если не нужна — можно не ставить.

## Примечание про /bots

Строка «Чат-бот (Gemma)» читает файл `gemma_state.txt`, который пишет
соседний бот-чат (загружена модель или выгружена). Без него покажет просто
статус процесса.
