# Дурак (Godot 4.7)

Карточная игра «Дурак» для Android.

* Режимы: подкидной, переводной, переводной-подкидной.
* Колода 24 / 36 / 52 карты.
* Боты: от 1 до 5, три уровня сложности. Сложный бот считает карты, а в конце партии перебирает варианты розыгрыша методом Монте-Карло.
* Сетевая игра по Wi-Fi: все в одной сети или на одной точке доступа, игры находятся автоматически, можно ввести IP вручную.
* Сетевая игра по Bluetooth: собственный Android-плагин `addons/durak_bt`, исходники в `android_plugin/`.
* Если сетевой игрок отключился, вместо него доигрывает бот.

## Сборка APK

Нужны Godot 4.7.2, Android export templates, Android SDK и JDK 17.

```bash
./build_apk.sh release   # → build/durak.apk
```

APK подписывается ключом `keystore/durak.keystore` (пароль `durak123`). Ключ лежит в репозитории специально, чтобы новые сборки ставились поверх старых. Для публикации в Google Play нужен свой секретный ключ.

## Тесты

```bash
godot --headless -s res://tests/sim.gd                # партии ботов во всех режимах, проверка правил
godot --headless -s res://tests/strength.gd -- 100    # сила сложного бота против среднего
godot --headless -- --net-test host & godot --headless -- --net-test client   # сеть по Wi-Fi
```
