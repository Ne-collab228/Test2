# Test2 — эксперименты с локальными моделями на CPU

Набор небольших проектов, собранных в облачном контейнере без GPU (4 ядра Xeon с
AVX-512/AMX, 16 ГБ RAM). Каждый проект лежит в своей папке и развивался в своей ветке;
ветка `ai_stats_server` — вершина цепочки и содержит всё.

| Папка | Что это | Ветка |
|---|---|---|
| [`gemma-server/`](gemma-server) | веб-чат с локальной Gemma 4 (FastAPI, потоковый вывод, раздумья) | `server` |
| [`gpt-train-ru/`](gpt-train-ru) | маленький GPT, обученный с нуля на русском (char-level) + готовые результаты | `ai` |
| [`gemma-telegram-bot/`](gemma-telegram-bot) | Telegram-бот на Gemma 4: прямой эфир, Стоп, фото, код с копированием | `ai-bottg` |
| [`server-control-bot/`](server-control-bot) | Telegram-пульт сервера: мониторинг, терминал, мини-браузер с сеткой-прицелом | `ai_stats_server` |
| [`ops/`](ops) | `watchdog.sh` — сторож, поднимающий упавших ботов | `ai-bottg` |

Ветки идут цепочкой: `server` → `ai` → `ai-bottg` → `ai_stats_server`.

## Быстрый старт

У каждого проекта свой `README.md` с установкой и командами. Общее для всех:

- Модели (`*.gguf`), токены ботов, секреты и логи **не хранятся в репозитории**
  (см. `.gitignore`); модели качаются скриптами `download_*.sh`, токены создаются у
  [@BotFather](https://t.me/BotFather).
- Python 3.10+, для `llama-cpp-python` нужен компилятор C/C++ и CMake.
