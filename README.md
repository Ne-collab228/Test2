# AIDA Py — информация об устройстве в стиле AIDA64 (Pydroid 3 / Kivy)

Тёмный интерфейс с красным акцентом, вкладки сверху, таблицы «параметр — значение»,
полосы заполнения, график и журнал событий.

| Вкладка | Что показывает |
|---|---|
| **Процессор** | название SoC (Snapdragon / Dimensity / Exynos / Tensor), производитель, архитектура, ABI, ядра и кластеры (Cortex‑A55, X1…), частоты каждого ядра, регулятор, загрузка, температура и все датчики, ОС и ядро |
| **Батарея** | уровень, статус, источник питания, здоровье, температура, напряжение, ток, мощность, ёмкость/износ, циклы; оценка оставшегося времени работы или зарядки, скорость разряда, **стабильность** разряда, график за 24 ч, **история зарядок** |
| **Система** | модель, производитель, версия Android, API, патч безопасности, сборка, root, ОЗУ, хранилища, экран, время работы, ядро |
| **Сообщения** | предупреждения устройства (перегрев, низкий заряд, мало ОЗУ/памяти, подключение/отключение зарядки, состояние батареи), фильтры, системный журнал (logcat/dmesg) |

## Запуск в Pydroid 3

1. Скопируйте `main.py`, `views.py`, `utils.py` в одну папку на телефоне.
2. Откройте `main.py` в Pydroid 3 и нажмите ▶. Kivy и pyjnius уже входят в Pydroid 3.

На ПК: `pip install kivy` (и по желанию `psutil`), затем `python main.py`.

## Структура

- `main.py` — приложение Kivy: шапка, панель вкладок, автообновление (3 с), строка состояния.
- `views.py` — тема, виджеты (строки, таблицы, полосы, график) и вкладки.
- `utils.py` — получение данных: Android API (pyjnius: `BatteryManager`, `Build`),
  `/proc`, `/sys`, `getprop`, `platform`, `os`; история батареи и монитор сообщений.

История батареи и сообщения сохраняются в `~/.aida_py/` (JSON). Замер батареи делается
раз в минуту, пока приложение открыто, — поэтому оценки времени и стабильности
появляются через несколько минут работы.

## Как добавить вкладку

В `views.py` (или в своём модуле, импортированном из `main.py`):

```python
@register_tab(order=50)          # order — позиция среди вкладок
class NetworkTab(BaseTab):
    title = "Сеть"

    def toolbar(self):            # необязательно: кнопки над вкладкой
        return [("Обновить", lambda btn: self.refresh())]

    def build(self):              # вызывается при каждом обновлении
        self.section("Сеть")
        self.row("Имя хоста", self.data.system.get("hostname"))
        self.bar("Сигнал", "75 %", 75)
        self.table(["Интерфейс", "IP"], [["wlan0", "192.168.1.5"]])
```

`main.py` автоматически создаст кнопку и экран. Данные для своих вкладок можно
хранить в `self.data.extra`.

## Ограничения Android

Начиная с Android 8–10 обычным приложениям недоступны часть файлов `/proc` и `/sys`
(общая загрузка ЦП, некоторые датчики температуры, ёмкость батареи) и чужие записи
logcat. В таких случаях выводится «Нет доступа» — приложение продолжает работать.
