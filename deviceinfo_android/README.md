# Device Info — характеристики телефона (нативное Android-приложение)

Информация об устройстве в стиле AIDA64, доработанная под **Honor X6c**
(NIC-LX1/2/3, MediaTek Helio G81 Ultra, Mali-G52 MC2, Android 15 / MagicOS 9),
но работает на любом Android 8+.

**Готовый APK:** [`releases/device-info-1.0.14.apk`](releases/device-info-1.0.14.apk)
(скачать → открыть на телефоне → разрешить установку из этого источника).

## Вкладки

| Вкладка | Что показывает |
|---|---|
| Процессор | Название SoC (словарь моделей + таблица MediaTek/Qualcomm/Exynos/Tensor), кластеры и типы ядер, частоты, загрузка по ядрам без `/proc/stat` (через cpuidle), свойства SoC для диагностики |
| GPU | Модель/драйвер Mali через OpenGL ES (EGL), лимиты, расширения, Vulkan; частота и загрузка, если прошивка открывает узлы MTK; иначе — макс. частота по спецификации |
| Батарея | Уровень, ток (учтены мА вместо µA и инвертированный знак у MagicOS), мощность, паспортная ёмкость (PowerProfile), фактическая ёмкость и износ, циклы, история зарядок, оценка времени, сырые значения |
| Экран | Реальное разрешение, 20:9, частоты обновления, HDR, яркость; диагональ не «выдумывается» по неверным xdpi |
| Память | ОЗУ (номинал «как на коробке»), RAM Turbo/zRAM, накопитель (номинал 128/256 ГБ), тип UFS/eMMC |
| Температуры | thermal_zone (если открыты), тепловой статус и запас до троттлинга (PowerManager), батарея |
| Система | Модель, MagicOS, Android, ядро, SELinux, root, сеть, Wi‑Fi, SIM, сервисы Google/Honor |
| Камеры | Настоящие мегапиксели (учтён биннинг 50 → 12.5 МП), сенсор, фокусное и ЭФР, диафрагма, OIS |
| Датчики | Полный список с параметрами |

Кнопка **«Отчёт»** собирает все вкладки в текст и отправляет через «Поделиться» —
удобно прислать разработчику, если что-то показывается неверно.

## Сборка

```bash
./gradlew assembleRelease          # app/build/outputs/apk/release/app-release.apk
./gradlew testReleaseUnitTest      # имитация Honor X6c (Robolectric), ~1 мин
```

Нужны JDK 17+ и Android SDK (platform 35, build-tools 35). Путь к SDK — в `local.properties`.

## Проверка

Эмулятора нет, поэтому проверка — **имитация Honor X6c на Robolectric**
(`app/src/test`): подложные `/proc` и `/sys` (как у G81 Ultra, с закрытыми и открытыми
датчиками температуры), свойства MagicOS, батарея в стиле MagicOS (мА, обратный знак),
экран 720×1604 с неверным xdpi. 25 тестов, все проходят. Ограничения имитации:
нет OpenGL/Vulkan, камер и датчиков — их нужно проверить на настоящем телефоне.
