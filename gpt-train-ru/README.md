# GPT с нуля на русском (char-level, CPU)

Маленький GPT (nanoGPT-стиль), который обучается **с нуля** на русском тексте
прямо на CPU и генерирует «псевдорусский» — текст, который выглядит и читается
как русский (правильные буквы, слоги, морфология, стиль), но без смысла.

Обучалось в облачном контейнере: 4 ядра Xeon, без GPU. Модель ~10.8M параметров,
char-level, словарь ~90 символов. За ~40 минут loss падает с ~4.6 (случайная
модель) до ~1.6, и в тексте появляется много настоящих русских слов и фраз.

> Это демонстрация того, *как* сеть учится, а не чат-бот. Осмысленно общаться
> такая модель не может — для этого нужны триллионы токенов и GPU-кластеры
> (см. любую готовую LLM). Здесь цель — наглядно увидеть обучение с нуля.

## Файлы

| Файл | Назначение |
|------|-----------|
| `build_corpus.py` | Собирает русский корпус из статей ru.wikipedia (чистый текст) |
| `train.py` | Обучает GPT с нуля; пишет `loss_log.csv`, `samples.txt`, `ckpt.pt`, `meta.json` |
| `plot.py` | Строит график обучения `loss.png` из лога |
| `generate.py` | Генерирует текст из лучшего чекпоинта (`ckpt.pt`), с temperature и top-k |

Веса, корпус и логи в репозиторий не коммитятся (см. `.gitignore`) — всё
воспроизводится скриптами.

## Как запустить

```bash
python3 -m venv venv && source venv/bin/activate
pip install torch --index-url https://download.pytorch.org/whl/cpu
pip install matplotlib

# 1) собрать корпус (по умолчанию ~мирные темы/случайные статьи -> data/russian.txt)
python build_corpus.py

# 2) обучить 10.8M модель (~40 мин на 4 ядрах CPU)
N_LAYER=6 N_HEAD=6 N_EMBD=384 BLOCK=128 BATCH=32 LR=8e-4 \
  WARMUP=100 DECAY_STEPS=1200 MAX_SECS=2400 EVAL_EVERY=50 \
  LABEL="русский" python train.py

# 3) график и генерация
python plot.py
N_NEW=600 TEMP=0.8 TOPK=40 python generate.py
```

## Параметры обучения (env)

| Переменная | По умолчанию | Что это |
|-----------|-------------|---------|
| `N_LAYER` / `N_HEAD` / `N_EMBD` | 8 / 8 / 512 | размер модели |
| `BLOCK` | 256 | длина контекста (символов) |
| `BATCH` | 32 | размер батча |
| `LR` | 3e-4 | базовый learning rate (+ warmup и косинусный спад) |
| `MAX_SECS` | 900 | лимит времени обучения, сек |
| `EVAL_EVERY` / `EVAL_ITERS` | 50 / 5 | частота и объём замеров |
| `DATA` | `data/russian.txt` | путь к корпусу |

## Что получается

Стадии (на loss):
- **~4.6** — старт, случайный набор символов
- **~2.5** — схвачена структура: правильные буквы, пробелы, шаблон статьи
- **~1.6** — много настоящих слов, верные окончания и падежи, целые фразы
  («американский футболист», «в 1978 году», «своего договора»), но смысл отсутствует

Дальше на маленьком корпусе начинается переобучение (train падает, val стоит) —
улучшать стоит не числом шагов, а размером/качеством корпуса.
