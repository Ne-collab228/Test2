# Telegram-бот на локальной Gemma 4 (CPU)

Телеграм-бот, который отвечает через локальную модель **Gemma 4 E4B** (GGUF),
запущенную на CPU-сервере. Работает по long-polling — **входящие порты не нужны**,
бот сам опрашивает Telegram. Удобно, чтобы общаться со своей моделью с телефона
из любого места.

## Возможности

- Диалог с памятью контекста (на каждого пользователя)
- **Переключатель раздумий** `/think` — модель сначала рассуждает, потом отвечает
- **Управление моделью из чата**: `/load` включает, `/unload` выгружает из RAM (~7 ГБ)
- Ленивая загрузка: если модель выключена, первое сообщение само её поднимет

## Команды

| Команда | Действие |
|---|---|
| `/load` | загрузить модель (если выключена) |
| `/unload` | выгрузить модель, освободить память |
| `/think` | вкл/выкл режим раздумий |
| `/reset` | сбросить диалог |
| `/status` | статус (модель вкл/выкл, раздумья, память) |
| любой текст | вопрос к модели |

## Установка

```bash
python3 -m venv venv && source venv/bin/activate
pip install -r requirements.txt   # llama-cpp-python

# модель GGUF (та же, что в gemma-server): положить в ./models/
#   gemma-4-E4B-it-Q4_K_M.gguf
```

## Токен

Получи токен у [@BotFather](https://t.me/BotFather) (`/newbot`) и положи его в файл
`bot_token.txt` рядом со скриптом (см. `bot_token.txt.example`), либо задай
переменную окружения `TG_TOKEN`.

> ⚠️ `bot_token.txt` в репозиторий не коммитится (см. `.gitignore`). Токен — это
> пароль от бота, не публикуй его. Если утёк — отзови через @BotFather.

## Запуск

```bash
source venv/bin/activate
python telegram_bot.py
```

Модель стартует выключенной (мгновенный старт, память свободна). Напиши боту
`/load` или любое сообщение — он загрузит Gemma и начнёт отвечать.

На 4 ядрах CPU ответ занимает ~15–40 сек (с раздумьями дольше).

## Переменные окружения

| Переменная | По умолчанию | Назначение |
|---|---|---|
| `TG_TOKEN` | — | токен бота (альтернатива файлу) |
| `MAX_TOKENS` | 512 | макс. длина ответа |
| `N_CTX` | 4096 | размер контекста |
