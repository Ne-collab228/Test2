# Telegram-бот на локальной Gemma 4 (CPU)

Телеграм-бот, который отвечает через локальную модель **Gemma 4 E4B** (GGUF),
запущенную на CPU-сервере. Long-polling — **входящие порты не нужны**. Удобно
общаться со своей моделью с телефона из любого места.

Есть **меню-кнопки снизу**, **автоподсказки команд** (при вводе «/») и
**настройки с сохранением** (контекст, лимит ответа, раздумья).

## Возможности

- Диалог с памятью контекста (на каждого пользователя)
- **Раздумья** `/think` — модель рассуждает перед ответом (медленнее, но умнее);
  раздумьям выделяется отдельный запас токенов, чтобы ответ не обрезало
- **Управление моделью из чата**: `/model` (или `/load` / `/unload`) — включить
  или выгрузить модель из RAM (~7 ГБ). Ленивая загрузка: первое сообщение само
  поднимет модель
- **Настройки с кнопками и сохранением** (в `chat_settings.json`):
  - 📏 `/context` — размер контекста модели: 2048 / 4096 / 8192 (смена перезагружает модель)
  - 🔢 `/limit` — лимит длины ответа: 256 / 512 / 1024 / 2048
- **Статистика скорости**: перед ответом — статус чтения контекста (ток/с фазы
  prefill), после ответа — скорость генерации (ток/с)

## Команды

| Команда | Действие |
|---|---|
| `/think` | вкл/выкл режим раздумий |
| `/context` | выбрать размер контекста (кнопки) |
| `/limit` | выбрать лимит длины ответа (кнопки) |
| `/model` | загрузить / выгрузить модель |
| `/reset` | сбросить диалог |
| `/status` | текущие настройки |
| `/help` | помощь |
| любой текст | вопрос к модели |

Контекст — общий (модель одна в памяти); лимит ответа, раздумья и температура —
на каждого пользователя. Все настройки сохраняются и переживают перезапуск.

## Установка

```bash
python3 -m venv venv && source venv/bin/activate
pip install -r requirements.txt   # llama-cpp-python

# модель GGUF (та же, что в gemma-server): положить в ./models/
#   gemma-4-E4B-it-Q4_K_M.gguf
```

## Токен

Получи токен у [@BotFather](https://t.me/BotFather) (`/newbot`) и положи его в файл
`bot_token.txt` рядом со скриптом (см. `bot_token.txt.example`), либо задай
переменную окружения `TG_TOKEN`.

> ⚠️ `bot_token.txt` в репозиторий не коммитится (см. `.gitignore`). Токен — это
> пароль от бота, не публикуй его. Если утёк — отзови через @BotFather.

## Запуск

```bash
source venv/bin/activate
python telegram_bot.py
```

Модель стартует выключенной (мгновенный старт, память свободна). Напиши боту
`/model` или любое сообщение — он загрузит Gemma и начнёт отвечать.

На 4 ядрах CPU генерация ~5 ток/с (с раздумьями дольше).

## Переменные окружения

| Переменная | По умолчанию | Назначение |
|---|---|---|
| `TG_TOKEN` | — | токен бота (альтернатива файлу) |
| `MAX_TOKENS` | 512 | дефолтный лимит ответа |
| `THINK_MAX_TOKENS` | — | (устарело; раздумьям даётся запас автоматически) |
