# AIDA Py — исследования для Honor X6c

Материалы, на основе которых исправляется приложение AIDA Py (информация об устройстве
в стиле AIDA64 для Pydroid 3). Целевой телефон: Honor X6c (NIC-LX1/2/3), MediaTek Helio
G81 Ultra, Mali-G52 MC2, 5300 мА·ч, Android 15 / MagicOS 9.

| Файл | Тема |
|---|---|
| [cpu.md](cpu.md) | Название SoC, частоты, загрузка ЦП, температуры, коды ядер ARM |
| [battery.md](battery.md) | Единицы тока/заряда у Honor, ёмкость, износ, циклы, зарядка |
| [gpu.md](gpu.md) | Видеочип: частоты, загрузка, OpenGL/Vulkan |
| tests.md | Результаты тестов на устройстве (будет добавлено) |
